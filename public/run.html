Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

01

Prerequisites

Use Node.js 24+, API credit and a supported model. Windows may require Git Bash. Python is needed only to regenerate student pages. No Slack token or external request-bin account is required.

node --version
npm --version
02

Install and create your .env file

From presentations enter the application, install locked dependencies, preserve an existing .env and enter your model key privately.

cd .\agent-sdk\lesson34-hooks-practice
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the terminal open and visit port 3134. Use the five buttons for the lab, concepts, setup, UML and coloured code walkthrough. Each run starts and closes its own loopback receiver.

npm start
# http://127.0.0.1:3134
04

Compare delivery and background work

Run successful delivery, HTTP 503, request cancellation and async logging. Inspect the real receiver receipts and elapsed-time records. Async mode drains its tracked background work before publishing final evidence.

npm run sample:env -- audit-success
npm run sample:env -- audit-error
npm run sample:env -- audit-abort
npm run sample:env -- async-audit
05

Observe a real permission notification

Choose Notification and leave the actual Read review pending for about nine seconds. Inspect the Notification callback and local Slack-format POST, then approve the Read. The CLI flag below explicitly scripts the same delayed approval for a demonstration.

npm run sample:env -- notification --approve-review
06

Force timeouts and repair a matcher

Compare one-second pre-tool and post-tool hook timeouts. Then compare lesson.txt as a matcher with the correct Read tool-name matcher. Read the actual native feedback and delivery records.

npm run sample:env -- timeout-pre
npm run sample:env -- timeout-post
npm run sample:env -- matcher-miss
npm run sample:env -- matcher-fixed
npm test

ANTHROPIC_API_KEY=your_api_key

# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. Select a fixed experiment and inspect the actual callbacks. Only a disposable lesson.txt Read is available. Change PORT if another application occupies 3134; never stop unrelated processes.
