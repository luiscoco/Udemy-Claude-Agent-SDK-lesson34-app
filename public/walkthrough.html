01

SubagentStop reference

The registered tracker extracts agent_id and agent_transcript_path from a real SubagentStop input. This app exposes only Read and launches no subagents. Its offline tracker test uses an explicitly labelled unit fixture; that fixture is not presented as a live SDK event.

02

Local Slack-format delivery

The Notification demo sends a real HTTP POST containing text to a loopback receiver. This verifies payload construction and error handling without external messaging. A real Slack workspace needs its own incoming webhook URL and secret handling; external Slack delivery is not implemented in this sample.

03

Notification availability

Current SDK documentation says permission_prompt occurs after a canUseTool request has waited about six seconds. This app waits roughly nine seconds in the scripted demonstration and verifies the actual Notification callback. Other interactive-only notifications are not assumed to occur.

04

Async task ownership

asyncTimeout is milliseconds; matcher timeout is seconds. Returning async output does not make side effects durable or guarantee delivery. The host tracks each background promise and drains it before final evidence. Background failures are caught and remain visible.

05

Event-specific timeout outcomes

Verified live: PreToolUse timeout blocks the Read, while PostToolUse timeout preserves its result. Late callback output is recorded as an observation, but the SDK discards output after its timeout. Other event outcomes are reference topics: UserPromptSubmit can block the prompt; Stop/SubagentStop count a timeout as no decision; PreModelSwitch can block the switch. Defaults and details depend on runtime version.

06

Matcher and event troubleshooting

Event names are case-sensitive. Tool-event matchers select names such as Read, not lesson.txt. Other events can use different matcher fields, and Stop ignores matchers. Check maxTurns, earlier denial and actual registration before assuming a hook is broken.

07

Input shape and recursion

updatedInput belongs inside hookSpecificOutput with hookEventName. Pairing it with defer discards the update. This app does not modify tool input. A UserPromptSubmit hook that launches work needs a re-entry guard to avoid recursive loops; this app starts no nested agent work.

08

Scope, cost and cleanup

Only a disposable lesson.txt Read is available. The $0.45 SDK budget threshold is not a prepaid cap. Timers, local HTTP connections and pending reviews are settled during cleanup. API keys, dependencies and all teaching media remain excluded from Git.

SubagentStop · reference only

This callback is registered, but the read-only lab launches no subagents. The offline test uses a clearly labelled fixture. No transcript is opened or forwarded by this callback.

Source: src/tracking-reference.ts · teaching reference

import type { HookCallback } from "@anthropic-ai/claude-agent-sdk";
// Reference callback: registered, but this read-only lab launches no subagents.
export function subagentTracker(
  record: (summary: unknown) => void,
): HookCallback {
  return async (input) => {
    if (input.hook_event_name !== "SubagentStop") return {};
    record({
      agentId: input.agent_id,
      transcriptPath: input.agent_transcript_path,
    });
    return {};
  };
}
